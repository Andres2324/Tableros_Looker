# Curso auto administrado para el diseño de Tableros Interactivos en Looker Studio 

Curso autoadministrado para la realización de tableros en Looker con datos de la vigilancia epidemiológica.

El curso esta diseñado para ser autoadministrado y se recomiendo realizarlo en paralelo al armado de un proyecto de tablero interactivo en Looker Studio.

Se organiza el contenido en 5 modulos y se incorpora links para profundizar en el manejo de la herramienta.
